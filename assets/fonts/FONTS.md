# Фирменные шрифты для лендинга

Источник: https://disk.yandex.ru/d/9PfhLLvwCD95jw/ФИРМЕННЫЕ%20ШРИФТЫ , проверено 22.09.2026.

- PT Root UI Regular/Bold: оригинальные WOFF2 из `PT-Root-UI.web (1).zip`. Наборный шрифт страницы. Лицензия SIL OFL 1.1 в `OFL.txt`, поставленном с архивом.
- Bebas Neue Bold: оригинальный OTF из `Bebas (альтернативный шрифт для заголовков)/BebasNeue-Bold.otf`, version 1.003. Заголовки и крупные цифры. Встроенная metadata указывает SIL OFL 1.1 и разрешает CSS @font-face; см. также https://github.com/dharmatype/Bebas-Neue . Кириллица есть, ₽ отсутствует, поэтому цены и основной текст набраны PT Root UI.
- Entrofly Bold: файл в общей папке НЕ скопирован в сайт и НЕ загружается. Приложенная Desktop EULA, пункты 2.1.3 и 3.1.1, требует отдельную веб-лицензию для CSS @font-face. Чтобы подключить его в живом тексте сайта, нужен документ на web use от правообладателя.

До разрешения на Entrofly использовать веб-разрешённый Bebas Neue как предусмотренную бренд-набором альтернативу. Старые Onest-файлы сохранены для отката, но больше не используются и не загружаются.
